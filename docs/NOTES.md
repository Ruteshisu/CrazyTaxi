# 質問・要望・今後の拡張メモ

## 本来質問したかった点 (自走中は止まらず、既定で進めた)
- 結果ランクのしきい値(S=60000/A=35000/B=18000/C=7000。デモAIは40秒で2万点超え。コンボ最大×10のため高スコアになりやすい)は仮置き。実プレイで調整してほしい
- 吹っ飛びギャグの「オイオイ度」の好み(もっと高く/回転多め/吹き出し増やす 等)
- ゲーム名「ブッ飛びタクシー / BOING TAXI」は仮名

## 第2回で出た確認事項・要望
- 既定解像度: ウィンドウ内の16:9領域 × devicePixelRatio(最大2) 、高さ上限1080。変えたい場合は config.render
- YouTube(参考動画)は見られないため、BGMは「速いパンクロック調」の方向性で自作(曲の再現はしていない)
- 得点バランス(コンボ倍率が効きすぎ)、ジャンプ台の高さ/個数、一般車の数は好みで調整してほしい(config.js)

## あると良かった素材・ツール (制約で未使用)
- 実音源(サンプル)があれば、衝突音/ボヨーンがもう少し豊かに。今はOscillator合成のみ
- ローカルに three.js を同梱できれば、オフライン動作・テストが容易(CDN依存をなくせる)
- glTF のキャラ/車モデル(今は箱ベースのローポリ)
- トゥーン/アウトライン用ポストエフェクト(three.js examples のアドオンが必要)

## 拡張アイデア
- 交通(NPC車)・信号・パトカー追跡(GTA要素)、ジャンプ台・屋根に着地ボーナス
- 通行人の種類(着ぐるみ/ハト/警官)、特定ギャグの専用リアクション(CT.Gags に追加するだけ)

- ハイスコアのlocalStorage保存、ステージ(別マップ/昼夜)、ゲームパッドの振動
