# 操作方法 (最終版)

| キー | 動作 |
|---|---|
| ↑ / W | アクセル |
| ↓ / S | ブレーキ → 止まったらバック |
| ← → / A D | ハンドル |
| SPACE | ハンドブレーキ(ドリフト)。曲がりながら押すとテールスライド |
| SHIFT | ブースト(ゲージ消費。ドリフト中に回復) |
| H | クラクション |
| M | 音 ON/OFF |
| P | 一時停止 (プレイ中) |
| R | リスタート (プレイ中) |
| ESC | デモ(タイトル)に戻る |
| F | FPS表示 (`?debug` でも表示) |
| ENTER / SPACE | 結果画面からもう一度 |
| 任意キー | デモ中にスタート |

ゲームパッド: 左スティックX=ハンドル / RT or A=アクセル / LT=ブレーキ / X=ドリフト / B=ブースト

## ルール
- 制限時間 75秒。お客さんを乗せて目的地に届けると 料金 + 時間延長(速いほど多い)
- お客さんは3色: 緑=近い / 黄=中 / 赤=遠い(遠いほど料金・延長が大きい)。リングの中で減速して(約47km/h以下)止まると乗車/降車
- 通行人をはねるとラグドールで吹っ飛び「芸術ポイント」。4秒以内に続けるとコンボ倍率(最大×10)
  - 即時: ヒット点(速度が高いほど高得点) × コンボ倍率 × ギャグ係数
  - 着地: 最高到達高さ・滞空時間ボーナス / 壁に当たると「壁ドン」ボーナス
- ドリフト点・高速走行点・コーン/ゴミ箱/ポスト撃破点も加算
- 目的地到着時は乗車中に稼いだ芸術点の12%がチップ
- 吹っ飛んだ通行人はそのまま倒れて残る(復活しない)。倒した分は車の前方の別の場所に新しい通行人が補充される。血や痛い描写は一切なし
- 演出は連続ヒットで段階的に派手になる(1発目は控えめ / コンボ2-3 / 4-6 / 7以上で星・揺れ・文字・フラッシュが増し、スローモーションはコンボ3以上のみ)
- お客さんはマップ中に常に12人散らばっている。誰でも拾える(一番近い客を矢印が案内)。客の頭上に大きな矢印、タクシーの屋根にも矢印
- 一般車(走行車・路駐車)・街路樹・街灯・コーン等は全部ふっ飛ばせる(建物は壁)。建物に強くぶつかると「きりもみ回転」して向きを変えて着地し、速度はほぼ落ちない
- ジャンプ台(オレンジの山型)で大ジャンプ。飛距離/滞空でボーナス
- 画面は16:9固定(余白は黒)。URLに `?fit=fill` で窓いっぱいの可変サイズ、`?h=720` で内部描画高さを固定
